1. Scope and System Architecture

This Privacy Policy applies to the official Android mobile application AMR Video Player (Package Identifier: com.amrton.amrvideoplayer), developed and published by Amrton ("we", "us", or "our").

AMR Video Player is engineered as an offline-first, zero-knowledge, hardware-accelerated media player designed to render locally stored video and audio formats (MKV, MP4, WebM, AVI, FLV, TS, 4K/HDR10+, AV1) with zero reliance on remote backend servers.

Core Guarantee: You are not required to create an account, log in, provide an email address, or disclose any personal identifiable information (PII) to utilize any feature or function in AMR Video Player.

2. Local Data Processing & Media Handling

To provide high-performance playback, subtitle synchronization, playlist management, and folder browsing, the application interacts exclusively with local device storage:

  • MediaStore Indexing: The app queries the Android OS MediaStore.Video content provider to index video titles, playback durations, frame dimensions, and MIME types stored on the device or inserted SD cards.
  • On-Device Thumbnail Caching: Video thumbnail previews and live scrubbing frames are generated dynamically on-device and stored inside the app’s private cache directory. These cached frames never leave your device.
  • Subtitle Parsing: Embedded subtitle streams (ASS, SSA, SRT, VTT, PGS, SUB) and external subtitle files loaded by the user are parsed in-memory on the local device.
  • Playback State & Resume Position: Video resume timestamps, audio boost levels, equalizer presets, playback speed preferences, and theme selections are stored strictly on-device in encrypted Jetpack DataStore Preferences and Room SQLite database tables.

3. Private Vault & Cryptographic Hygiene

AMR Video Player includes an on-device Privacy Vault for isolating sensitive personal videos behind PIN code authentication:

  • Cryptographic Salting: User PINs and security answer hashes are computed using SHA-256 combined with a random, device-bound unique cryptographic salt. Plaintext PINs are never stored anywhere on the file system.
  • Constant-Time Verification: Authentication checks utilize constant-time comparison algorithms to mitigate side-channel and timing attacks.
  • Operating System Screen Shield (FLAG_SECURE): When browsing the Private Vault or entering credentials, the application activates Android's WindowManager.LayoutParams.FLAG_SECURE. This prevents unauthorized screenshot capture, screen recording, and exposure in the Android Recent Apps / Multitasking preview switcher.
  • Zero Cloud Backdoor: Amrton does not possess master decryption keys or remote access mechanisms. If you uninstall the app or clear app data without unhiding vaulted videos, recovery is physically impossible from remote sources.

4. Network Streams & Local Area Casting

  • User-Initiated Network Streams: If you enter a direct media URL (HTTP, HTTPS, RTSP, RTMP, HLS, DASH), the app initiates a direct client-to-server connection strictly to the third-party endpoint specified. Amrton operates no intermediary proxy, relay, or telemetry collector.
  • Local Wi-Fi Casting: Chromecast and DLNA casting protocols operate strictly within your local wireless network (LAN) directly between your phone and your receiver display device. No streaming metadata is transmitted outside your local network.

5. Android System Permissions Matrix

AMR Video Player complies with Android’s Least-Privilege Security Principle and Google Play Scoped Storage directives. The table below provides full transparency regarding each declared permission:

Android Permission Classification Target API Functional Justification
READ_MEDIA_VIDEO Dangerous (Runtime) API 33+ (Android 13+) Allows the player to index and play local video files located on device storage without requesting broad storage access.
READ_MEDIA_VISUAL_USER_SELECTED Dangerous (Runtime) API 34+ (Android 14+) Supports Android 14+ Partial Media Picker so users can grant access strictly to selected clips.
POST_NOTIFICATIONS Dangerous (Runtime) API 33+ (Android 13+) Displays continuous playback notification controls (Play, Pause, Seek, Skip) on lockscreen and notification shade.
FOREGROUND_SERVICE_MEDIA_PLAYBACK Special Type (Service) API 34+ (Android 14+) Ensures uninterrupted background audio playback when the user switches apps or turns off the screen.
INTERNET & ACCESS_NETWORK_STATE Normal (Install-Time) All Versions Used strictly when the user streams an online video URL or discovers local Chromecast devices over Wi-Fi.
WAKE_LOCK Normal (Install-Time) All Versions Prevents the screen from dimming or locking during active full-screen video playback.
MODIFY_AUDIO_SETTINGS Normal (Install-Time) All Versions Permits hardware volume control integration, 5-band equalizer adjustments, and software audio pre-amp boost.

Prohibited Permissions Confirmation: AMR Video Player does not request or utilize broad storage permissions (MANAGE_EXTERNAL_STORAGE), nor does it access Location, Camera, Contacts, Microphone, SMS, Call Logs, or Unique Hardware Telemetry IDs (IMEI/MAC).

6. Third-Party Integrations & Zero-Tracker Policy

Commercial surveillance architectures violate our engineering standards. AMR Video Player adheres strictly to a zero-third-party tracking policy:

  • No Commercial Ad Networks: Zero integration with Google AdMob, Unity Ads, AppLovin, ironSource, or Facebook Audience Network.
  • No User Tracking SDKs: Zero inclusion of Google Firebase Analytics, Mixpanel, AppsFlyer, Adjust, Segment, or Facebook Graph SDK.
  • No Data Brokers: We do not sell, rent, monetize, or disclose user data, usage telemetry, or device states to any commercial entity.

Exercise of Legal Rights

Because 100% of your data remains exclusively on your local hardware device, you maintain immediate self-service execution over all statutory data rights without submitting formal requests:

  • Right of Access & Portability: All settings, playlists, and histories are stored in standard local SQLite / DataStore formats accessible directly on your device.
  • Right to Erasure (Right to Be Forgotten): Users can completely wipe all thumbnails, playback history, resume points, and cached metadata in Settings > Storage & Cache > Clear All Cache.

8. Data Retention, Custody & Erasure

Data retention is governed strictly by the physical state of the host device:

  • Instant Cache Purge: Within the app settings, tapping "Clear Playback History" or "Clear Thumbnail Cache" executes an immediate local disk purge.
  • Application Removal: Uninstalling the application triggers Android’s operating system to permanently delete the entire app sandbox directory (/data/data/com.amrton.amrvideoplayer), including all databases, preference files, and cached assets.
